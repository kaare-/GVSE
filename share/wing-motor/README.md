An unequal phrase, stereo, so the two wings can be heard apart. This file is here so it can be downloaded. It is not part of the voxel engine.

Eleven seconds. Pulse gestures are b1 clicks only, and they last anywhere from about half a second to a second and a half. Steady gestures bring in the 162 Hz tone from b2, and they are not the same length either. The silences between them run from a fifth of a second to three quarters. The left channel is the left wing. The right channel is the right wing.

`motor-halfgap-irregular.wav` is seed 0. The last half-second is silent.

The test note is with the research documents, not in this repository.
